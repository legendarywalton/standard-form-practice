How to find intercepts
  • x-intercept: let y = 0, then solve for x. The point looks like (x, 0).
  • y-intercept: let x = 0, then solve for y. The point looks like (0, y).
How to graph from standard form
  1. Find the x-intercept and the y-intercept.
  2. Plot both points.
  3. Connect them with a line.

Tap the grid to place a point. Tap a point again to remove it. With a keyboard, use the arrow keys and Enter.

How to read a standard form story
  • Each item gets its own term: (cost of one) times (how many). The two terms add up to the total.
  • The x-intercept means you got only the x item. The y-intercept means you got only the y item.
  • A combination works if substituting it makes the equation true.
Two things to remember
  • Solution: substitute the point's x and y. If both sides are equal, the point is a solution.
  • HOY: Horizontal line, slope zerO, equation Y = a number. VUX: Vertical line, slope Undefined, equation X = a number.
