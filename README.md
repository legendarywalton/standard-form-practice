# Standard Form Practice

A single-page practice app for 8th grade math (linear relationships, standard form `Ax + By = C`).

Modes: intercepts, graphing on a grid, word problems, quick checks (solutions, HOY/VUX) and a 10-question practice quiz. Questions are generated fresh each time and every answer comes with worked steps.

No build step and no dependencies: open `index.html`, or serve the repo with GitHub Pages.
